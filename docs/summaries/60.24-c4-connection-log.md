# 60.24 C4 step 1 connection log: as built (60.20 W2 step 1)

Design: 60.02 C4 (Q5: logfmt only); spec and lead answers 2026-11-01 (memory levels 2/3 warn, keep `ts=`, 256 KiB
outbox per worker with an early wake at half). Code: `server/src/logs.rs` (level filter, logfmt value escaper, ts,
Outbox, the `connlog` writer thread), `server/src/worker/connlog.rs` (Why / Proto / Auth, ConnLog side vector, the three
line kinds), `worker/conn.rs` (accept_all, adopt, close_client), the close sites (Why argument), `main.rs` (`say!`
macro, level guards, `logs::flush` at exit), `mem.rs` (Log::send levels), `metrics.rs` (`log_dropped`,
log_nowait = warn). Operations: 40.01 "Logging"; flags: 40.03. Step 2 (`--log-streams`, stream_close, rule ids, UDP
counters) is not built.

## Decisions as built
1. Flags `--log-level error|warn|info|debug` (default info) and `--log-conns` (off); both are `--config` keys. With the
   defaults stderr is byte for byte base-5 (checked against the base-5 binary with timing numbers masked: default,
   warnings, a bad argument; the only differences are the new `--help` text and, with `--metrics-interval`, the new
   `log_dropped=` key).
2. Levels: error = fatal startup lines (they `exit`; never filtered). warn = `warning:` lines, the TLS "no KeyUpdate"
   line, the kTLS starve and KeyUpdate-refused lines (metrics::log_nowait), memory "opening/reading failed" lines,
   memory level changes into level 2 or 3. info = listening, capabilities, SMTP hint, other memory and tcp level lines,
   SIGHUP / drain / shutdown lines (main::log), metrics lines (the metrics thread is not started below info; the final
   line is not written), conn_close / conn_refused. debug = conn_open. A `--config` file warning is shown unless the
   parsed level is error (an unparsable command line shows it). Connection lines are info: `--log-conns` with
   `--log-level warn` or `error` is off altogether (no peer address, no side vector, no writer thread; review).
3. Line: `finalwisp: ev=conn_close ts= w= cid=W:SEQ ip= [via=] tls= proto= auth= dur_ms= streams= refused= rx= tx= why=`.
   ts: CLOCK_REALTIME_COARSE, formatted by hand (civil-from-days), only when a line is written. ip / via: from
   Worker::peers_of (60.22), which is now filled when `want_peer = clientip || log_conns`; behind a trusted proxy
   `ip` is the header's client and `via` the proxy (only when they differ). IPs are canonical (mapped IPv6 = IPv4).
4. rx / tx: TCP_INFO tcpi_bytes_received / tcpi_bytes_acked at close (`net::bytes_rx_tx`), wire bytes. The peer's FIN
   counts one byte in tcpi_bytes_received; in CLOSE_WAIT it is subtracted, so rx equals what the client sent (compat
   logs.py checks both exactly). tx = acknowledged bytes (what was sent and not yet acked at close is not counted).
5. Per connection state lives in `Worker::connlog: Vec<Option<ConnLog>>` by slab slot (empty when off; Client stays 512
   bytes). streams = CONNECTs that became a stream, refused = CONNECTs refused (policy, caps, memory, rate); invalid /
   duplicate stream ids are not counted.
6. why: `close_client`, `begin_close`, `abort_client`, `reset_client` take a `Why`; `connlog::set_why` keeps the first.
   Earlier, more precise sites set it before the generic close (tls_read_records: not TLS = protocol_error, EOF =
   client_close; wisp_reject: auth reasons = auth_failed, else protocol_error; Wisp before INFO = protocol_error;
   close_notify = client_close). The drained close after a WS Close keeps client_close; a linger timeout or shutdown
   says server_close. A failed client read or write passes `Why::Io`; close_client (log on) names it from errno
   before any other syscall: ETIMEDOUT / EHOSTUNREACH = dead_peer, ECONNRESET / EPIPE = client_close, anything else on
   a kTLS socket = tls_error (EBADMSG, a failed KeyUpdate), the TX record limit = tls_error (review). OFF, the call
   sites only pass a different constant. Mapping per site: grep `Why::`.
7. Writer: workers append whole lines to their `Outbox` (Mutex<Vec<u8>>; the lock is held for a memcpy) directly at
   the close, not via a run_timers move (simpler: one copy; the lock is only contended for the writer's swap every
   100 ms). Over 256 KiB the line is dropped (Stats::log_dropped, Outbox counter); crossing half the cap unparks the
   writer. One `connlog` thread (started only with --log-conns) swaps every outbox each tick and writes chunks of whole
   lines (<= 4096 bytes, so atomic on a pipe) with blocking write(2); a failed write drops the chunk. It prints
   `ev=log_dropped n=` and `ev=refused_suppressed n=` at most once per second. At exit (exit0) main asks the writer
   for a final round (`logs::flush`: a request counter, the writer acks after writing every outbox and the counters)
   and waits at most 500 ms. The writer starts after the startup lines (eprintln may write a line in parts; review);
   lines of connections closed before that wait in the outboxes. Connections still open at a forced exit
   (`--drain-timeout 0`, a second SIGTERM, the drain timeout) get no conn_close line: workers are not asked to log
   them (the "exiting with N connection(s)" line counts them). The other stderr writers (startup, metrics, memlog, log_nowait) are unchanged:
   one write per line each, so lines never interleave.
8. conn_refused: accept-time refusals (C3a --max-conns, C3b --max-conns-per-ip of a direct peer) never reach adopt; one
   line each, at most 20 per second per worker, the rest counted (Outbox::suppressed). 429 / 403 / 503 after the
   HTTP request are conn_close lines (an adopt failure, no TLS state or epoll refused, gives conn_refused
   why=server_close) with why=limit / pressure_shed / auth_failed / server_close.
9. Privacy: IPs only with --log-conns; no hostnames, auth names, keys or passwords. Values are escaped (`logs::value`:
   quotes, backslash, `=`, space, control bytes and DEL as \xNN), fuzzed in http-parse against an unescaper.

## Off cost (disassembly vs base-5 ed867a7, bench/tools/disasm_norm.py --fold finalwisp::worker)
Logic changes are in control paths: accept_all / adopt (want_peer,
log hooks), close_client / begin_close / abort_client / wisp_reject / ws_fail (the Why argument, one connlog length
check), tls_drive, target_eof, on_message / process_frames / read_client (inlined close sites and the on_connect
counters: one `connlog` length check per CONNECT), run (inlined close sites), main / cli / signal_loop / exit0 / log /
mem sampler / Log::send / log_nowait / Stats::named (levels, the new metric). Per-byte functions: read_target differs
by one `mov $N,%edx` (the Why of the broken-splice close); push_wisp lost one `test/je` pair (LLVM, no source change
there); write_target, flush_bucket, flush_pending, read_udp, after_write, process_input, stage_upload are offsets only.
Final build (md5 64467e17): 46 functions differ, 21 offsets only, 25 logic. OFF A/B on VPS2
(raw data (not published): regress lo,tls,idle n=16, then n=32, swap and A/A; 0 LOSS). This line
first named VPS1 (the planned box); no VPS1 run is on record.

## Tests
Unit: logfmt escaping, level filter, ts format (leap day, 2099), outbox cap / drop / take, chunking on line ends,
cli flags, io_why. Worker: `conn_log_lines_name_the_close_reason` (peers_of filled without C2, v1 close after a WS Close with
streams / refused and exact rx / tx, not-HTTP = protocol_error, unmasked frame = ws_error, EOF = client_close,
shutdown = server_close, 25 accept refusals = 20 lines + 5 suppressed); 4 mutations each caught. compat `logs`
(B+22, B+23): default has no connection lines; exact wire bytes; ws_error; hs_timeout; 500 quick connections = 500
lines, no drops; warn / error / debug; warn + --log-conns = no connection lines; a line queued just before exit is
written; a 1000-connection refusal flood = 20 lines + suppressed = the refusal count; a
stalled stderr: echo works, dropped lines counted (ev=log_dropped = metric), lines + dropped = connections.
