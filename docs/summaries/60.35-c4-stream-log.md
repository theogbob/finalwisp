## Decisions as built
1. `--log-streams` (off; a `--config` key; info level: off altogether with `--log-level warn|error`). Independent of
   `--log-conns`: the connection's cid entry (ConnLog) is made when either is on, `conn_close` is written only with
   `--log-conns`, `conn_open` (debug) only with `--log-conns`. `want_peer = clientip || ((conns || streams) && info)`;
   the outbox and the writer thread start when either is on.
2. State: `Worker::streamlog: Vec<Option<StreamLog>>` by target slot, empty when off (Target does not grow; every hook is
   behind `!self.streamlog.is_empty()` or `cfg.log_streams`). The host is cloned in `new_target` only when on.
   `new_target` takes `udp` so the kind is right when it fails at once.
3. `ev=stream_close`: one line per stream that got a Target (TCP, UDP, the wsproxy target). `dst`: `won()` (the first
   address when the first attempt won, else `net::peer_ip(fd)` once per stream), `udp_open` (the connected address).
   TCP up/down: one TCP_INFO read at close (tcpi_bytes_acked - 1 for the active open's SYN, measured on Linux 6.x;
   tcpi_bytes_received). UDP: side counters (below).
4. **Close is split in two (deliberate, disasm-driven):** `slog_close` (called from `close_target` with the target still in
   the slab and its socket open) only takes the entry, the reason, the kind, the TCP_INFO numbers, the client IP and the
   end time into `Worker::sdone`; `slog_flush` (from `reap_dead`, end of every loop turn) formats and pushes the lines.
   A first cut formatted in `close_target`: `close_target` shares a call-graph cycle with the per-byte paths
   (flush_bucket, target_eof, write_target), and a `write!` with a Worker field let `self` escape there, so LLVM reloaded
   and re-checked fields after syscalls in read_target, write_target, stage_upload and flush_bucket (OFF build). With the
   split those four are offset-only again (variants built and compared, `disasm_norm`). `close_client` flushes `sdone`
   after drop_streams, before `unload` (review: main flushes the log and exits once no connection is left).
5. `why` (first site wins, `slog_why`): explicit at the sites that know (client CLOSE = client_close, connection end =
   conn_close in drop_streams, DNS inflight cap, address-rule refusal after DNS with the rule of the first address,
   upstream connect / timeout / proxy failure, the C6 ip_form / loopback refusals, pace_fail, every shed with its rule,
   a UDP connect failure); else `stream_why(reason, phase)` with phase Dns (resolving, no address yet), Connect, Open:
   none = client_close, 0x41 invalid, 0x48 policy, 0x49 pressure `over_credit` (the one unnamed 0x49 site, the upload
   over-credit cap in upload.rs, left untouched: per-byte code), any other code when Open = target_close (0x02, and
   0x03 / 0x47 from net::data_reason), 0x42 in Dns = dns_fail, else connect_fail. A wsproxy target sends no CLOSE code
   (`target_eof` passes None to close_target), so `target_eof` names its reason from the code first (`slog_raw_reason`,
   one test per wsproxy close; review).
6. Rule ids only on the log path: `Policy::refusal(udp, host, port)` and `Filter::refusal(ip)` mirror `allows()` /
   `allowed()`, which are unchanged. Property "refusal is Some iff not allowed": unit tests (Filter: 128 flag combinations
   x 29 addresses; Policy: mixed rules and hosts) and the `policy-host` fuzz target (both, 1.47 M runs in 120 s, clean).
7. `ev=stream_refused`: CONNECTs refused before any Target (0x41 bad type / host, 0x48 request rules or `--no-udp`, 0x49
   per-connection / rate / admission caps). At most 20 per second per worker (own window), the rest counted in
   `Outbox::stream_suppressed` and written as `ev=stream_refused_suppressed n=` (at most once per second). The refused
   host is cut to `policy::MAX_HOST` bytes before escaping (`host_len=` when cut): a CONNECT body can be a whole 16 MiB
   frame (review). `logs::value` escapes every byte that is not valid UTF-8 as `\xNN` (a cut inside a character, or a
   host that is not UTF-8 at all), so every log line is valid UTF-8 (review round 2; unit test in logs.rs).
   `stream_close` lines are not rate-limited: they share the 256 KiB outbox per worker, over it they are dropped and
   counted in `log_dropped`.
8. UDP counters (C4 UDP): `udp_send_one` returns Ok(true) sent / Ok(false) dropped (full buffer, soft error twice), and
   only sent datagrams are counted (review). `udp_send` adds behind one not-taken test per datagram when off (no
   duplicate send path);
   `read_udp` sums the recvmmsg batch in a separate loop behind one test per batch; `udp_open` counts the datagrams
   queued while resolving.
9. C6 (`--upstream`): the line has `upstream=1`; `dst` is the proxy and up/down include the proxy handshake bytes.

## Off cost (disassembly vs eb7f6d1, plain `cargo build --release` both sides, `bench/tools/disasm_norm.py --fold finalwisp::worker`)
1835 -> 1847 functions, 49 bodies differ; classes in raw data (not published).
- **Offset-only (same instructions, field offsets only):** read_target, write_target, stage_upload, flush_bucket,
  flush_pending, after_write, read_client, push_continue, tls_drive, process_input, accept_on, hs_put,
  pend_account, pend_resume_all, stream_token, wisp_reject, ws_fail, line_head, log_refused.
- process_frames: offset-only (one field moved to offset 0: `mov N(R)` -> `mov (R)`) plus the inlined wsproxy
  upgrade's `new_target` call passing `udp` (two pushes, once per wsproxy connection).
- on_message (on_connect inlined): the five refusal hooks (cold calls) and the new `new_target` argument; the TCP DATA arm
  has register-allocation changes only (a few spills / reloads moved, no new branch or call). The UDP DATA arm
  (udp_send inlined) gains the one test per datagram (decision 8); udp_send_one (per datagram) is 62 -> 65 instructions:
  the errno class lookup became a byte table instead of a jump table, for the sent / dropped result (no extra syscall). Removing all five refusal hooks (a variant) still
  leaves on_message differing, from the inlining alone.
- Logic, per stream or per event: new_target (host clone + slog_open when on), start_connect (first refused address,
  the rule), won (dst), try_connect / resolve (upstream_fail, dns_inflight), close_target (+8: the test and call),
  drop_streams, proxy_fail / proxy_io / proxy_connect (C6 handshake), read_udp (one test per batch), adopt, log_close,
  target_eof (+18: the wsproxy reason, once per target close), close_client (+6: the sdone flush test).
- run (+77 / -11 after register normalization, the rest block order): the inlined `shed()` copies (a test and an
  inlined `slog_why`, ~17 instructions each, memory-pressure path), reap_dead's `sdone` test (2), the connect timer.
- Elsewhere: Filter::allowed calls `embedded_v4` out of line now (once per resolved address), `logs::value` out of line,
  main / cli / log thread.
- **Measurement left to the lead:** OFF A/B (`lo`, `tls`, `idle`, `udp-rr --conns 1 --streams 1`, n=32) and ON runs.
